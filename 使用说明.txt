========================================================================
                        打印机共享修复工具  使用说明
========================================================================

一、这个程序做什么
   解决 Windows 10 / Windows 11 局域网内打印机共享连不上的问题。

   界面按两步来选：
     第一步：这台电脑是哪种情况？
        [ 本机接有打印机 ]   打印机插在这台电脑上，要让别的电脑连过来打印
        [ 本机没有打印机 ]   打印机在别的电脑上，这台电脑要连过去用
     第二步：这台电脑是什么系统？
        [ Windows 10 ]   [ Windows 11 ]    程序会自动标出推荐的那个

   点下去之后，程序会自动开启共享所需的服务、打开网络发现、放行防火墙、
   处理来宾访问，并修掉 0x0000011b / 0x00000740 这些经典报错，
   每一步都会显示执行结果。

   右上角还有一个「设置」按钮，可以看到当前版本号和每个版本的更新内容。
   接打印机的那台电脑和要用打印机的那台电脑，需要分别各跑一次对应的方案。

二、运行环境
   Windows 10 1809 及以上 / Windows 11，64 位（x64）。
   本目录是自包含版本：目标电脑不需要安装 .NET 或其它运行时，
   把整个文件夹拷过去就能用（不要只拷 exe 这一个文件）。

三、使用方法
   1. 把整个文件夹拷到需要修复的那台电脑上（U 盘、共享目录、网盘都行）。
   2. 双击 PrinterShareFixer.exe，Windows 会弹出“用户账户控制”，
      选择“是”（程序需要管理员权限才能修改服务和防火墙）。
   3. 第一步按这台电脑的实际情况选：
      · 打印机插在这台电脑上、要让别人连过来 → 选“本机接有打印机”；
      · 这台电脑要用别人共享的打印机、但连不上 → 选“本机没有打印机”。
   4. 如果选了“本机没有打印机”，可以在下面的输入框里填写接打印机那台电脑的
      名称或 IP（例如 PC-01 或 192.168.1.10）。填了以后，修复的最后一步会自动
      测试连通性（ping、445 端口、135 端口、共享列表），直接告诉你卡在哪一环。
   5. 第二步按这台电脑的系统点 Windows 10 或 Windows 11（程序会自动标注推荐）。
   6. 弹出确认框后点“开始修复”，等待进度跑完（通常 10-60 秒）。
   7. 全部显示完成后，回到需要用打印机的那台电脑上重新连接测试。

   提示：两台电脑最好各跑一次——接打印机的那台选“本机接有打印机”，
   要用打印机的那台选“本机没有打印机”。

   修复期间打印服务会短暂重启，建议先保存正在打印的文档。

四、修复之后还是连不上，按顺序排查
   1. 确认打印机已共享：在接打印机的那台电脑上，右键打印机 →
      打印机属性 → 共享 → 勾选“共享这台打印机”。
   2. 确认两台电脑在同一网段、能互相 ping 通。
   3. 在客户端的资源管理器地址栏直接输入 \\对方电脑名 或 \\对方IP，
      看能不能看到共享的打印机。
   4. 提示要用户名密码时，用户名写 对方电脑名\对方电脑上的账号。
   5. 第三方安全软件（360、火绒、企业 EDR）可能拦截 SMB / RPC，
      可临时退让后重试。
   6. 跨网段、跨 VLAN、带路由器的场景：勾选高级选项中的
      “防火墙规则允许所有远程地址”后重新修复。
   7. Windows 11 24H2 且启用了受保护的打印模式时：勾选高级选项中的
      “关闭 Windows 受保护的打印模式”后重新修复。

五、日志与还原
   日志：C:\ProgramData\PrinterShareFixer\Logs\printer-share-fix-日期时间.log
         （界面上点“打开日志”可直接打开该目录）
   备份：C:\ProgramData\PrinterShareFixer\Backups\日期时间\*.reg
         修复前程序会自动导出相关注册表项；需要还原时双击对应的
         .reg 文件并确认导入，然后重启电脑。

六、命令行版本（可选，见 psfix-cli 文件夹）
   适合批量处理或远程排查：
        psfix version                           查看版本号与更新内容
        psfix detect                            只读检测，不改任何设置
        psfix plan win11-consumer               查看客户端方案包含哪些动作
        psfix run win10-provider                预演（不会真的修改）
        psfix run win11-consumer --yes --target 192.168.1.10
                                                真正执行（需在管理员命令行里运行）

七、注意事项
   · 程序没有数字签名，SmartScreen 或杀毒软件可能提示“未知发布者”，
     选择“仍要运行”即可；企业环境请先走内部白名单流程。
   · “关闭密码保护的共享”“允许不安全的来宾登录”会降低局域网安全性，
     建议只在可信内网使用；不放心可把高级选项中对应勾选去掉，
     改成在客户端用本机账号登录。
   · 程序只修复本机的共享配置，不会替你创建打印机共享。
