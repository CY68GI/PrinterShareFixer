【重要】这个版本不自带 .NET 运行时，第一次使用前必须先安装它
========================================================================

一、你要装什么
   名称：.NET Runtime（.NET 运行时）10.0 - x64
   地址：https://dotnet.microsoft.com/download/dotnet/10.0

   打开上面的链接，在 “.NET Runtime 10.x” 那一行点 Windows → x64，
   下载安装包（文件名类似 dotnet-runtime-10.x.x-win-x64.exe），双击安装，
   一路下一步即可。装完一般不需要重启（重启一次更稳妥）。

   说明：程序只用到基础运行时（Microsoft.NETCore.App），
   所以装 “.NET Runtime” 就够了；如果页面上你更习惯装
   “.NET Desktop Runtime 10.x”（桌面运行时），也可以，它包含前者。
   两个都装不会冲突。

   也可以直接双击本目录下的 “下载.NET运行时.url”，它会用浏览器打开下载页。

二、怎么确认装好了
   · 最省事的办法：双击本目录下的 “启动程序.bat”。
     它会先检查 .NET 10 运行时是否已安装：装了就直接启动程序；
     没装就提示你，并自动打开下载页面。
   · 直接双击 PrinterShareFixer.exe 也可以。运行时缺失时，
     Windows 会弹出 “必须安装 .NET” 之类的提示框并给出下载链接。
   · 注意要装的是 “.NET Runtime” 或 “.NET Desktop Runtime”，
     不是 “ASP.NET Core Runtime”。

三、为什么这个版本要自己装运行时
   本目录是“不自带运行时”的版本，压缩包比自带运行时的版本小很多，
   适合已经装过 .NET 或者批量部署到多台电脑的场景。
   如果不想装运行时，请改用另一个压缩包：
       PrinterShareFixer-<版本号>-win-x64.zip
   那个版本里已经打包好了 .NET 运行时，解压即可运行。

四、这个程序还需要别的东西吗
   不需要。Windows App SDK 已经随程序打包，只需要 .NET 10 桌面运行时这一项。
   系统要求：Windows 10 1809 及以上 / Windows 11，64 位（x64）。

五、更多说明
